# Smart Boot Menu — Organization Configuration (`.github`)

This repository holds organization-wide community health files, GitHub profile metadata, issue/PR templates, and shared CI/governance conventions for the [Smart Boot Menu](https://github.com/smart-boot-menu) GitHub organization.

## Contents

- `profile/README.md` — Public GitHub organization overview.
- `SECURITY.md` — Default vulnerability disclosure and security policy.
- `CONTRIBUTING.md` — Organization-wide contribution guidelines and interface-change process.
- `CODE_OF_CONDUCT.md` — Contributor Covenant Code of Conduct.
- `PULL_REQUEST_TEMPLATE.md` — Default pull request checklist.
- `ISSUE_TEMPLATE/` — Structured bug report, feature/RFC, and security advisory templates.

## Canonical Architecture & Specs

All architectural specifications, Architecture Decision Records (ADRs), threat models, and roadmaps live canonically in [`smart-boot-menu/sbm`](https://github.com/smart-boot-menu/sbm).
