# Smart Boot Menu — Organization Configuration (`.github`)

This repository holds organization-wide engineering rules, community health files, GitHub profile metadata, issue/PR templates, and shared CI/governance conventions for the [Smart Boot Menu](https://github.com/smart-boot-menu) GitHub organization.

## Contents

- `AGENTS.md` — Canonical organization-wide engineering rules and Open-Source Reuse & Engineering Principles for all agents and contributors.
- `agent-reference.md` — Operational procedures (Shared Interface Change Protocol, Rust Validation Checklist, Benchmark Evidence Recording, Proportional Build-vs-Reuse Evaluation).
- `profile/README.md` — Public GitHub organization overview.
- `SECURITY.md` — Default vulnerability disclosure and security policy.
- `CONTRIBUTING.md` — Organization-wide contribution guidelines and interface-change process.
- `CODE_OF_CONDUCT.md` — Contributor Covenant Code of Conduct.
- `PULL_REQUEST_TEMPLATE.md` — Default pull request checklist.
- `ISSUE_TEMPLATE/` — Structured bug report, RFC/interface proposal, and security advisory templates.

## Canonical Architecture & Specs

- Normative specifications, Architecture Decision Records (ADRs, including [`ADR-010`](https://github.com/smart-boot-menu/docs/blob/main/architecture-decisions/ADR-010-open-source-reuse-and-engineering-principles.md)), threat models, and testing standards live canonically in [`smart-boot-menu/docs`](https://github.com/smart-boot-menu/docs).
- Executive vision, architecture summary, roadmap, repository map, and agent launch prompts live in [`smart-boot-menu/sbm`](https://github.com/smart-boot-menu/sbm).
